# ofxManifold -- the mutation gates.
#
# Each gate breaks one thing on purpose and expects a suite to notice. CI runs
# them in parallel shards (tests/run_gates.py --shard i/N); locally:
#
#     python3 tests/run_gates.py                  every gate, one after another
#     python3 tests/run_gates.py --only "trim"    gates whose name contains it
#     python3 tests/run_gates.py --shard 2/6      what CI shard 2 of 6 runs
#
# A gate is a block of lines, blocks separated by a blank line:
#
#     gate:    what the break is, said as the bug ("Unrenormalized bias")
#     file:    the file it breaks
#     find:    text that must appear in that file exactly once
#     replace: what it becomes
#     nl:      yes   (optional: \n in find and replace means a newline)
#
# find and replace are taken literally: everything after "find: " to the end of
# the line, spaces included. No quoting, no escaping, no regular expressions.
# tests/check_workflow.py checks every anchor matches exactly once, so a
# refactor that moves the code under a gate fails locally rather than in CI.
#
# Adding a gate: add a block. Nothing else to change.
